海上风电机组维检 Agent

自然语言询问风机状态、告警、工单安排、故障处理办法与作业合规性

本系统能做什么

可以回答
  • 风机型号、运行状态、最近一次告警
  • 指定时间段内的告警记录
  • 故障原理、触发条件、排查步骤
  • 工单优先级、状态、备件与观察时间
  • 重复故障、远程复位、关单与换板的合规判定
无法回答
  • 现场安全条件（母线电压、挂牌上锁、验电等）
  • 责任归属与调查结论
  • 备件实物库存与到货时间
  • 海况、天气与人员资质

以上事项随题资料均无记录，系统会明确标注「需要现场核实」，不会推测。

时间范围一律按闭区间理解；数据覆盖 2026-07-01 00:00:00 ~ 2026-07-20 23:59:59。
